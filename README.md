# Study02_ToDoList_B

하루 10–20개의 할 일을 **업무 · 개인 · 공부**로 나눠 관리하는 개인용 할 일 관리 웹 앱입니다.
설치나 서버 없이 브라우저에서 바로 실행되고, 데이터는 localStorage에 저장되어 새로고침해도 유지됩니다.

> 현재 단계: **구현 완료**

## 주요 기능

- 할 일 추가 · 수정 · 삭제
- 완료 체크 (완료 항목은 목록 아래로 정렬)
- 카테고리 분류(업무/개인/공부)와 필터
- 전체 및 카테고리별 진행률 표시
- 완료 항목 일괄 삭제
- 새로고침 후에도 데이터 유지 (localStorage)

## 기술 스택

- HTML, CSS, 순수 JavaScript (프레임워크·라이브러리·빌드 도구 없음)
- `index.html`을 더블클릭하면 서버 없이 실행


## 실행 방법

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저로 엽니다.
3. 테스트는 `tests.html`을 브라우저로 열어 확인합니다.
